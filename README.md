# Система учёта туристических путёвок

## О проекте

Информационная система предназначена для **централизованного учёта туристических путёвок**.  
Она позволяет сотруднику туристического агентства добавлять и изменять сведения о путёвках,  
контролировать их доступность, осуществлять поиск по заданным параметрам и оформлять  
путёвки для клиентов.

Проект выполнен в рамках лабораторной работы №2 по документированию  
программных проектов с использованием GitHub, Markdown и PlantUML.

## Цель и задачи

**Цель:** создание информационной системы, которая упрощает учёт туристических путёвок,  
сокращает время поиска подходящего предложения и обеспечивает контроль доступности  
путёвок при их оформлении.

**Задачи:**

- хранение сведений о туристических путёвках и клиентах;
- добавление, изменение и удаление информации о путёвках;
- поиск путёвок по направлению, датам, стоимости и другим параметрам;
- просмотр подробной информации о выбранной путёвке;
- проверка наличия свободных мест;
- оформление выбранной путёвки на клиента.

## Актёры и их роли

| Актёр | Роль |
|-------|------|
| **Менеджер** | Добавление, изменение и удаление путёвок, просмотр данных, поиск, проверка доступности, оформление путёвок, управление сведениями о клиентах, управление менеджерами |
| **Клиент**   | Поиск и фильтрация предложений, просмотр подробной информации, выбор подходящей путёвки |

## Основные функции системы

- Авторизация пользователя
- Добавление новой туристической путёвки
- Редактирование данных существующей путёвки
- Удаление путёвки
- Просмотр списка туристических путёвок
- Поиск и фильтрация путёвок
- Просмотр подробной информации о путёвке
- Управление менеджерами

## Архитектура и реализация

В системе используется классическая **трёхуровневая архитектура**.  
Проект реализован на языке программирования **Python** в виде консольного приложения.
